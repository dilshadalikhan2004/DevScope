# LinkedIn Project Launch Announcement

🚀 **Excited to share my latest analytics portfolio platform: DevScope – Developer Career Intelligence Platform!**

As developers and hiring managers navigate shifting remote work policies, salary adjustments, and the rapid explosion of Generative AI tools, making data-driven talent decisions is more critical than ever.

To tackle this challenge, I built **DevScope**, an end-to-end data analytics platform synthesizing multi-year **Stack Overflow Developer Surveys (2021–2024)**, **GitHub Octoverse trends**, and **Tech Job Market Postings**.

### 💡 Key Insights Uncovered:
1. **The AI Productivity Paradox**: 72.1% of developers now use AI assistants, but senior developers adopt AI at 2x the rate of junior developers.
2. **Compensation Acceleration**: Developer salary doubles from Entry ($52k median) to Senior ($115k median) within 6 years, with the steepest jump occurring at Year 3.
3. **Language Velocity**: Rust (+28.6% 4-year CAGR) and TypeScript lead growth momentum, while legacy web languages (PHP, -4.2% CAGR) steadily decline.

### 🛠️ Tech Stack & Key Features:
- **Python 3.12, Pandas, NumPy, SQL, PostgreSQL, SQLAlchemy**
- **Multi-stage ETL Pipeline** handling multi-year data cleaning & schema normalization
- **60 Consolidated SQL Queries** covering compensation, technology co-occurrence, and supply/demand gaps
- **8-Tab Interactive Streamlit Dashboard** featuring 2–3 year skills forecasting
- **Automated PDF Executive Report Generator** using ReportLab
- **Docker Compose & GitHub Actions CI/CD**
