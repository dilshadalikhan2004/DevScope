# DevScope Resume Bullet Points (Google STAR Framework)

Tailored for applications to the **Google Data Analytics Apprenticeship** and Data Analyst roles.

---

### Option 1: Feature Project Bullet Points

- **Engineered DevScope**, a production-grade developer career intelligence platform analyzing 9,000+ multi-year Stack Overflow survey responses (2021–2024), Tech Job Postings, and GitHub Octoverse trends to drive workforce decision-making.
- **Architected multi-stage Python ETL pipeline** utilizing Pandas, NumPy, and SQLAlchemy to standardize currency, clean missing values, and transform complex multi-select tag strings into a relational PostgreSQL star schema.
- **Developed 60 consolidated SQL queries** evaluating compensation drivers, technology growth momentum (CAGR), AI adoption metrics, and talent supply vs. employer demand gaps.
- **Built an interactive 8-tab Streamlit & Plotly dashboard** featuring 2–3 year skills forecasting models and executive KPI cards, delivering evidence-based recommendations that model a 22% reduction in international hiring costs and 30% reduction in developer churn.
- **Packaged full production environment** with Docker Compose, automated ReportLab PDF report generation, and GitHub Actions CI/CD pipeline achieving 100% test coverage with pytest.
